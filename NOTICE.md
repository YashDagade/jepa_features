This supplement adapts the Stable WorldModel framework for the LeWM cue-binding
study in Tunnel Rooms. Its package and import names are retained for checkpoint
compatibility. The upstream MIT copyright and license notice is preserved in
`stable-worldmodel/LICENSE`. It identifies the upstream software, not the
anonymous submission's authors.

The supplement includes local modifications to the environments, training,
readouts, and diagnostics described in the accompanying paper. The paper is
supplied separately from the code archive.
