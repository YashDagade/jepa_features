# LeWM in Tunnel Rooms

This package contains the environments, dataset interfaces, LeWM implementation,
and CEM/GD planning solvers used by the accompanying study. The package name
`stable_worldmodel` is retained for compatibility with saved model configurations.

From the supplement root, install with:

```bash
python -m pip install -e './stable-worldmodel[train,format]'
```

See the root `README.md` for workflows and `REPRODUCIBILITY.md` for experimental
settings and the limits of reproducing historical results. The inherited MIT
license is in `LICENSE`; upstream attribution is in the root `NOTICE.md`.
