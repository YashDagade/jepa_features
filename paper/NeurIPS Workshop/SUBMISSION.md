# PTA short-submission handoff

Prepared for anonymous review on September 5, 2026. The PDF is ready for the
submission form; no submission has been sent.

## Files and form

- Upload `main.pdf`, generated by `make build`. It includes the four-page
  main paper, references, and technical appendices in one PDF.
- The packaged copy and self-contained LaTeX ZIP are under ignored
  `runs/pta_feedback/narrative_revision/submission/` at the repository root.
- `submission_fields.json` provides the exact paper title/abstract, short-paper
  selection, suggested topics/keywords, and optional TL;DR for copying into
  [OpenReview](https://openreview.net/group?id=NeurIPS.cc/2026/Workshop/PTA).
- Enter the actual ordered author list using OpenReview profiles. The form
  requires author-email sharing and accepted-paper public-release statements,
  and specifies CC BY 4.0. These author-side fields have not been filled or
  accepted by this preparation workflow.

## Verified requirements

The [PTA call for papers](https://ptaworkshop.github.io/call-for-papers.html)
allows four-page short submissions, uses double-blind review, and waives the
NeurIPS Paper Checklist. Its linked
[NeurIPS 2026 formatting instructions](https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip)
exclude references and optional technical appendices from the content limit
and require appendices in the same PDF. The workshop is non-archival.

- The main paper occupies pages 1–4; references start on page 5. The complete
  PDF is 22 pages. Primary probes, reconstructions, energy landscapes, and
  planning results appear in the main paper.
- `neurips_2026.sty` is byte-identical to the freshly downloaded official file;
  `dblblindworkshop` is selected, with neither `final` nor `preprint` enabled.
  The required workshop title is set.
- US Letter pages, official margins, 10-point body and table text, line
  numbers, a one-paragraph abstract, figure captions below, and table captions
  above are retained. Author identities and acknowledgments are omitted.
- Type 3 figure fonts were replaced by embedded TrueType. Numerical results,
  source image pixels, figure sizes, and plotting geometry are unchanged.
- All 22 references resolve. The build has no overfull boxes or undefined
  citations/references. PDF text and metadata do not reveal author identities.
- The live OpenReview invitation permits a PDF up to 50 MB; this PDF is under
  3 MB. It contains the `Short submission (4 pages)` option.

The deadline is **September 5, 2026, AoE**. The live invitation records its due
instant as **September 6, 2026, 11:59 UTC** (07:59 EDT). Use that due time,
not the later invitation-expiration timestamp.

The existing one-seed, source-revision, diagnostic, and transition-exposure
limitations remain explicit. Formatting readiness does not change those
scientific boundaries. Funding/competing-interest acknowledgments belong in
the accepted final version under the official instructions.

## Rebuild

```bash
make -C 'paper/NeurIPS Workshop' build
```

The source archive contains only active LaTeX, bibliography, official style,
build files, and referenced figure PDFs. It requires Tectonic and its TeX bundle
but no experiment checkpoints, private paths, or raw datasets. Build/package
hashes and the format audit are recorded in `data/submission_format_audit.json`.
