# Tunnel Rooms datasets

Large HDF5 files are not included. Generate the Color, Shape, and Palette
conditions with the commands in [TUNNEL_ROOMS.md](TUNNEL_ROOMS.md). All outputs
use a directory you choose through `STABLEWM_HOME`; no private dataset service
or account is required.

The release includes deterministic collection, scenario manifests, exact
trajectory rerendering, coordinate-probe sidecars, and objective-exposure
counts. Newly generated corpora follow the released protocol but are not
claimed to reproduce the paper's archived dataset hashes. The paper used
historical collection revisions; seed equality alone does not establish
byte-for-byte equivalence across revisions.
